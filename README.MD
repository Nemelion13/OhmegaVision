## Ohmega Resistor


    ** This document explains that the project relies on a CustomTkinter interface combined with computer vision, allowing users to obtain a resistor's value in ohms by holding it in front of their webcam. It is also possible to load an image of the component directly from the computer.**

## Installation
    read requirements.txt : pip install -r requirements.txt
